# ISO 🔄️ CSO Compressor 🚀

A high-performance Android application designed to compress standard ISO disk images into compressed CSO (Compressed ISO) format and decompress them back to ISO with maximum speed and zero storage overhead.

## 🛠️ Built With & Powered By
- **Core Engine**: A faithful, optimized native Kotlin port of RetroChef's [csochef](https://github.com/RetroChef/csochef) Python script, utilizing high-performance `Deflater` / `Inflater` raw DEFLATE streaming and Android's Storage Access Framework (SAF).
- **UI Framework**: Jetpack Compose & Material 3.
- **Architecture**: MVVM with Kotlin Coroutines.
